---

## ⚡ Interactive Highlights

- 🛸 **Persistent 3D Three.js Galaxy:** Real-time 3D camera trajectory tracking, gravitational mouse light tracking, and 2,000+ interactive particle nodes with velocity-driven warp effects during fast scrolling.
- 🧪 **Interactive 3D Lab Widget:** Direct click & drag 3D geometry inspector with inertia physics, scroll wheel zoom, dynamic shape switching (*Torus Knot, Icosahedron, Dodecahedron, Sphere*), and material modes (*Holographic Wireframe & Refractive Solid Glass*).
- 🎴 **3D Perspective Tilt Cards:** Real-time mouse coordinate raycasting on all cards with dynamic specular radial lighting reflection.
- 🎯 **Kinetic Custom Cursor:** Smooth trailing magnetic follower with velocity elongation and click feedback.
- 📟 **Interactive Devbox Terminal:** Fully functioning interactive CLI emulator supporting commands like `help`, `whoami`, `skills`, `projects`, `experience`, `contact`, `hire`, `cat cv.txt`, and `confetti`.
- 🔊 **Native Web Audio Synthesizer:** Procedural sci-fi audio effects synthesized in the browser using the Web Audio API without external audio file dependencies.
- 📄 **Curriculum Vitae Document Inspector:** Built-in modal viewer with direct print/PDF capabilities.

## 🛠️ Tech Stack

- **Frontend:** React 19, TypeScript, Vite, Tailwind CSS v4
- **3D Graphics:** Three.js (WebGL, BufferGeometries, PointLights, FogExp2, Particle Shaders)
- **Audio:** Web Audio API (OscillatorNode, GainNode, Dynamic Envelope Curves)
- **Icons & FX:** Lucide React, Canvas Confetti

## 🚀 Getting Started

### Prerequisites
- Node.js 18+ (tested on Node v24)
- npm or pnpm

### Installation

```bash
# Clone the repository
git clone https://github.com/Emmility-king/3d_portfolio.git

# Navigate into project directory
cd 3d_portfolio

# Install dependencies
npm install

# Start development server
npm run dev
```

### Production Build

```bash
npm run build
npm run preview
```
